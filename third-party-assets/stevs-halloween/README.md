# Stev's Halloween imported sweet textures

Thirteen unchanged 16x16 item sprites are retained from Stev's Halloween 1.0.0 by Stev51 under the MIT licence. The files are used as ItemsAdder sweet icons in this project.

The source URL, source JAR checksum, source paths, target paths and per-file SHA-256 values are kept in asset-source-manifest.json. The full MIT text is in LICENSE and in the ItemsAdder pack's THIRD_PARTY_LICENSES folder. No models, mob logic, events or other gameplay code from the source mod are included.
