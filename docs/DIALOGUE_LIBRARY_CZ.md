# Dialogy s BetonQuest

Používáme BetonQuest místo UplineDialogues. Připravený testovací balíček a přesný postup instalace, vytvoření Citizens vesničana, přiřazení jeho ID a nastavení odměn jsou popsány v hlavním návodu:

- README projektu
- Soubory ukázkového balíčku: betonquest/QuestPackages/warriorland_halloween_dialogues/

Důležité: soubory dialogů jsou YAML konfigurace, nikoli import do webového editoru. Po vytvoření NPC je třeba jeho skutečné Citizens ID doplnit do package.yml. HalloweenCore pak při dokončení přidělí fragmenty pouze jednou.
