# ItemsAdder content retained by HalloweenCore

Copy the warriorland_halloween folder into plugins/ItemsAdder/contents/ and run /iazip. Use /iainfo to verify that the generated resource pack is hosted and delivered.

The namespace now includes the key for locked underground room chests and the retained imported sweet sprites only. No mob models, boss models, event sounds, sky shader, block overrides, custom gear or graveyard furniture are part of this content package.
