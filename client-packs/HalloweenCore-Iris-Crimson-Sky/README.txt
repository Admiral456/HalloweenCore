WARRIORLAND HALLOWEEN — IRIS CRIMSON SKY
=========================================

This is an OPTIONAL client-side shader pack. It is NOT part of the required ItemsAdder resource pack.

Target: Minecraft Java Edition 1.21.10, with Iris installed and a compatible graphics setup.
The files use standard Iris/OptiFine-style gbuffers shader programs, but the release target is Iris; do not assume OptiFine compatibility without testing.

INSTALL
1. Download and unzip this artifact.
2. Put the ZIP itself into .minecraft/shaderpacks/ (do not extract it there).
3. Start Minecraft with Iris, open Options > Video Settings > Shader Packs.
4. Select "HalloweenCore Iris Crimson Sky".
5. Use the shader-pack settings page "HALLOWEEN" to adjust the crimson sky, twilight glow and blood moon intensity.

WHAT IT DOES
- Keeps Minecraft's base sky, vanilla moon texture and moon phases.
- Applies a time-aware crimson grade at dawn and dusk and a subtle rose-red night tint.
- Tints the vanilla moon red at night without replacing its texture or its phase.
- Softens the colour under rain rather than washing the sky into one flat red.

COMPATIBILITY
- The look is entirely client-side; ViaVersion/ViaRewind do not install or translate shaders.
- For multiplayer, this pack is optional. Players without Iris can use the normal Halloween items, sounds and models from the server's ItemsAdder resource pack.
- Do not enable a separate shader pack which also replaces the sky if the two produce conflicting colours.
- This shader has static validation in CI, not a substitute for an in-game test on your exact GPU/driver. If the sky renders incorrectly, disable this pack; it does not affect the server.

The shader sources and artwork are part of the HalloweenCore project.
